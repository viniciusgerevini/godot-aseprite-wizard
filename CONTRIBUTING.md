# Contributor guidelines

This document summarizes the main points for people interested in contributing to this project.

## Reporting bugs

If you find a bug, first check if there isn't already an open issue for it. If not, feel free to open a new issue in this repository.

To help streamline the process, please include in your issue a description and reproduction steps, and also the Godot version and Operational System used.

## Feature requests

For feature requests, open an issue in this repository explaining the new feature and at least one use-case for it. To keep this project maintainable, I try to make sure the proposal solves a common problem or enhance important experiences, avoiding features that are too niche or that there are simple workarounds for them.

Having said that, I'm happy to discuss any feature proposal, even if you feel it might no fit the criteria, as we might find a middle ground that works best for the project.

## Code contributions and pull requests

Even though I'm happy to accept impromptu pull requests, it's better to open an issue first to discuss the contribution and avoid frustrations.

Minor bugs and small improvements are usually straight forward, but for significant changes we need to make sure they solve a real problem and that we have a chance to discuss architectural changes to ensure code quality and alignment with the project's direction.

### AI Usage

No AI generated content (e.g. code, assets, docs) is accepted in this project. I'm aware not all AI usage can be detected, but I ask you to please respect this decision and don't try to send AI generated or assisted contributions.

### PR etiquette

- Make sure relevant areas are manually tested when making a change (Importers, AnimationPlayer, Sprites, and AnimatedSprites docks).
- Include a description of the problem being solved, a link to the issue if it exists, and any details you think might help with the review, such as use-cases, usage instructions, and alternative approaches considered.
- Ideally, contributions should already have been discussed in an issue, but I'll do my best to accept your contribution regardless. Just keep in mind that impromptu contributions might take longer to get merged as I need to make sure it won't be a burden to the project.
